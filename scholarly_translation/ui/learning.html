למידת שפה

עזרה ללמידת שפה

התוכנה עודכנה, אבל החלון הזה עדיין מחובר לגרסה הקודמת. סגרו והפעילו מחדש את התוכנה, ופתחו את חלונית הלמידה מהחלון החדש כדי לראות ערבית ולבחור פרק התחלה.

בחרו שפה כדי לראות את הספרים, ההתקדמות וההגדרות שלה.

הוספת ספר

ספר שתורגם כאן מתווסף מספריית התרגומים (כפתור "למידת שפה" ליד הספר). אפשר גם להעלות כל ספר EPUB בעברית; שמו יהיה שם הקובץ.

מה לומדים

רמת מאמץ: כמה מהטקסט מוחלף בחומר חדש בשפה הנלמדת.

איך זה עובד?

לכל שפה היסטוריה ורמת מאמץ משלה. אפשר ללמוד כמה שפות וכמה ספרים במקביל.

האחוזים מגבילים חומר חדש; מילים שכבר פגשתם ממשיכות להצטבר בפרקים הבאים.

לומדים מההקשר, עם אפשרות לבקש פירוש בלחיצה. אין פירוש אוטומטי צמוד למילה בשום רמה.

מפתחות API

המפתח נשמר בזיכרון השרת המקומי לאורך הפעלה זו; אינו נשמר בדפדפן או בכתובת. סימון "לזכור" שומר אותו מוצפן במנהל האישורים של Windows, כך שיישאר גם אחרי סגירת התוכנית. אפשר גם להגדיר אותו במסך התרגום הראשי.

רשימות מילים בשש שפות, כולל ערבית ספרותית

רשימות השכיחות מנחות את תחילת הלמידה בחמש השפות האירופיות; לערבית ספרותית יש רשימת התחלה מקומית. המודל יכול לבחור גם מילים נוספות לפי הספר ורמת המאמץ; 500 מילים הן יעד ראשון.

מילים ומבנים חדשים נוצרים בעזרת המודל ונשמרים להמשך. הפירושים והדקדוק אינם עוברים ביקורת לשונית נפרדת.
