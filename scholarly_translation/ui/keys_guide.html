מדריך

איך משיגים מפתח API?

כדי לתרגם עם מודל משלכם צריך מפתח API מאחד הספקים. העמוד הזה הוא קובץ סטטי מהמחשב שלכם: הוא לא שולח שום מפתח, דוא"ל או נתוני שימוש לשום מקום.

מה זה מפתח API?

מפתח API הוא מחרוזת סודית שמזהה את החשבון שלכם אצל ספק המודל. התוכנה משתמשת בו כדי לשלוח את הטקסט לתרגום, והספק מחייב את החשבון שלכם בעלות השימוש ישירות. אל תשתפו אותו ואל תפרסמו אותו.

שימו לב: מנוי ChatGPT או מנוי Claude אינו כולל קרדיט API. ה-API הוא חשבון נפרד עם תשלום נפרד לפי שימוש, ויש להטעין בו קרדיט מראש.

המלצה

OpenAI gpt-6-luna גם כמתרגם וגם לבדיקת האיכות (QA) — האפשרות הזולה ביותר מבין המודלים שהתוכנה מכירה את מחירם. מחיר הקטלוג (model-catalog-2026-10-05): $0.10 למיליון טוקני קלט ו-$0.50 למיליון טוקני פלט. העלות האמיתית לספר שלכם תלויה באורכו; תצוגת האומדן באפליקציה מחשבת אותה לכל מסמך לפני ששולחים משהו, וזה האומדן שכדאי להסתמך עליו.

שלבים לפי ספק

OpenAI

  1. היכנסו או הירשמו, פתחו את עמוד מפתחות ה-API של OpenAI ויצרו מפתח חדש (Create new secret key). העתיקו אותו מיד — הוא מוצג פעם אחת.
  2. פתחו את עמוד החיוב של OpenAI והוסיפו קרדיט מראש (בדרך כלל המינימום הוא כ-5$; הספקים משנים סכומים מדי פעם).
  3. מומלץ לכבות הטענה אוטומטית (auto-recharge) ולהגדיר מגבלה חודשית.
  4. הדביקו את המפתח באפליקציה וסמנו "לזכור במחשב הזה".

Anthropic (Claude)

  1. היכנסו או הירשמו, פתחו את עמוד המפתחות של Anthropic ויצרו מפתח (Create Key). העתיקו אותו מיד.
  2. פתחו את עמוד החיוב של Anthropic והוסיפו קרדיט מראש (בדרך כלל המינימום הוא כ-5$).
  3. מומלץ לכבות הטענה אוטומטית ולהגדיר מגבלת הוצאה חודשית.
  4. הדביקו את המפתח באפליקציה וסמנו "לזכור במחשב הזה".

DeepSeek

  1. היכנסו או הירשמו, פתחו את עמוד המפתחות של DeepSeek ויצרו מפתח. העתיקו אותו מיד.
  2. הטעינו קרדיט בעמוד ההטענה של DeepSeek (בדרך כלל יש סכום מינימום קטן).
  3. אם קיימת הטענה אוטומטית — כבו אותה, ועקבו אחרי היתרה, והגדירו מגבלה חודשית אם האתר מאפשר.
  4. הדביקו את המפתח באפליקציה וסמנו "לזכור במחשב הזה".

המפתח נשמר מוצפן במנהל האישורים של Windows בחשבון המשתמש שלכם בלבד, ולא בקובצי הפרויקט. אפשר למחוק אותו בכל עת מחלון המפתח באפליקציה. אתרי הספקים והסכומים עשויים להשתנות; אם עמוד נראה אחרת, חפשו באתר הספק "API keys" או "billing".

Guide

How do I get an API key?

To translate with your own model you need an API key from one of the providers. This page is a static file on your computer: it sends no key, email or usage data anywhere.

What is an API key?

An API key is a secret string that identifies your account with the model provider. The app uses it to send text for translation, and the provider bills your account directly for the usage. Never share or publish it.

Note: a ChatGPT or Claude subscription does not include API credit. The API is a separate account billed separately by usage, and you add credit to it in advance.

Recommendation

OpenAI gpt-6-luna for both the translator and quality review (QA) — the cheapest option among the models whose prices the app knows. Catalogue list rate (model-catalog-2026-10-05): $0.10 per million input tokens and $0.50 per million output tokens. The real cost of your book depends on its length; the app's own cost preview calculates it per document before anything is sent, and that is the estimate to rely on.

Steps by provider

OpenAI

  1. Sign in or sign up, open the OpenAI API keys page and create a new secret key. Copy it immediately — it is shown once.
  2. Open the OpenAI billing page and add prepaid credit (usually a minimum of about $5; providers change these amounts).
  3. We recommend turning auto-recharge off and setting a monthly limit.
  4. Paste the key in the app and tick "Remember on this computer".

Anthropic (Claude)

  1. Sign in or sign up, open the Anthropic keys page and create a key. Copy it immediately.
  2. Open the Anthropic billing page and add prepaid credit (usually a minimum of about $5).
  3. We recommend turning auto-recharge off and setting a monthly spend limit.
  4. Paste the key in the app and tick "Remember on this computer".

DeepSeek

  1. Sign in or sign up, open the DeepSeek keys page and create a key. Copy it immediately.
  2. Add credit on the DeepSeek top-up page (usually there is a small minimum amount).
  3. If automatic top-up exists, turn it off, keep an eye on your balance, and set a monthly limit if the site allows.
  4. Paste the key in the app and tick "Remember on this computer".

The key is stored encrypted in the Windows Credential Manager under your user account only, not in project files. You can delete it at any time from the app's key dialog. Provider sites and amounts may change; if a page looks different, search the provider's site for "API keys" or "billing".
