# עיצוב הספרייה באפליקציה עצמה

16.10.2026. העיצוב שנבנה באב הטיפוס (`design/pixel-library/library.html` בענף `design/pixel-library-prototypes`) הוא עכשיו הממשק הרשמי של האפליקציה. חוזה העבודה: `audit/contracts/ui_library_redesign.md`.

## הגישה

הממשק הקיים קיבל "עור" חדש והורחב. הוא לא נכתב מחדש. המזהים ב־`ui.html`, הלוגיקה ב־`ui.js` וכל נקודות השרת נשארו כמו שהם. העיצוב יושב בשכבה נפרדת, `ui-theme.css`, שנטענת אחרי `ui.css`. הרכיבים החדשים הם מודולים קטנים שמתחברים לרכיבים הקיימים:

| קובץ | תפקיד |
| --- | --- |
| `ui-theme.css` | צבעים, גופן Frank Ruhl Libre (מגיע עם האפליקציה, דרך `/fonts/frank-ruhl-libre.ttf`), כותרת, כפתורים, כרטיסים, מדף, טופס, כריכייה |
| `cat.js`, `cat.css` | החתול: מקומות ישיבה על משטחים אמיתיים, ליטוף והרמה, מחשבות בעברית ובאנגלית, הגדרות בכותרת התחתונה (נשמרות ב־localStorage) |
| `shelf.js` | הספרייה כמדף. נבנה מפריטי הרשימה ש־`ui.js` מצייר, ולכן כל הפעולות האמיתיות עובדות כמו קודם |
| `segments.js` | בחירות קצרות ככרטיסי בחירה. התיבה הנפתחת המקורית נשארת מקור האמת |
| `bindery.js` | הכריכייה בעיבוד ובתוצאה. `ui.js` ממשיך להפעיל את `#pixel-book` דרך `data-phase`, ועכשיו גם דרך `data-step` |
| `learning-theme.css` | אותה שפה חזותית בחלון למידת השפה |

`ui.js` השתנה רק בכמה שורות מוגנות (`window.libraryCat?.` ודומיהן). בלי הקבצים החדשים האפליקציה עובדת כרגיל.

## השלבים

1. **בסיס:** ערכת נושא, גופן, לוגו (חתול מציץ מעל ספר) ואייקון לשונית, והחתול.
2. **הספרייה:** מדף של ספרים מט בגווני בד, בלי ברק ובלי פרספקטיבה.
   - ריחוף או מעבר במקלדת מסובב ספר בהיפוך שטוח, מהשדרה אל הכריכה.
   - ספר פתוח מוצג בכרטיס עם הפריט המקורי ועם כל הפעולות שלו.
   - חיפוש ומיון, תצוגת מדף או רשימה, ו"עוד מדפים" בספרייה גדולה.
   - מחיקה עדיין מבקשת אישור.
3. **התחלת תרגום:**
   - האפשרויות מקובצות לארבעה חלקים: איך לתרגם, מודל ועלות, ספרים סרוקים וגופן, המונחים שלי.
   - בחירות קצרות מוצגות ככרטיסים.
   - מגש מאויר באזור הקובץ.
   - הערת "מה חסר" כשכפתור התרגום כבוי.
4. **עיבוד ותוצאה:**
   - כריכייה עם דף שמתהפך בתלת־ממד ואותיות שמשנות צורה באוויר.
   - חפצים על השולחן לפי שלב העבודה, ומקום לחתול ליד הספר.
   - השהיה, שגיאה וסיום מקפיאים את הסצנה.
5. **חלון הלמידה:** אותה שפה חזותית, והחתול. הוא לא יושב על טקסט הקריאה.
6. **בדיקות, אנגלית ומיזוג.**

## באגים שנמצאו ותוקנו בדרך

- **שורת "תצוגת ניסיון":** ב־`qualityLabel` היה כתוב `returnt(` במקום `return t(`. בגלל זה דף התוצאה זרק שגיאה בכל עבודת Auto. זה תוקן ונוספה בדיקת רגרסיה.
- **אייקון הלשונית:** בשלב 1 הוא קודד עם מירכאות פנימיות שקטעו את המאפיין. זה תוקן, ונוספה בדיקה שמוודאת קידוד מלא.

## מה לא הועבר מאב הטיפוס, ולמה

- **כרטיס הקטלוג הצדדי ורשימת "מה חסר" נפרדת:** באפליקציה כבר יש תקציר בחירות (צ'יפים) והערת `send-note`, שמבוססים על לוגיקת האימות האמיתית. שכפול שלהם היה יוצר שני מקורות אמת.
- **לוח ההדגמה ונתוני הדמה:** הם שייכים לאב הטיפוס בלבד.
- **צמצום תנועה:** האפליקציה שומרת על הכלל הקיים שלה. כשמערכת ההפעלה מבקשת צמצום תנועה, ההנפשות נעצרות והחתול מתחיל במצב שינה. אפשר להעיר אותו בהגדרות.

## בדיקה ידנית מקומית

```powershell
python scripts/design/serve_ui_sandbox.py --data outputs/ux/ui-redesign/data --port 8840
node --experimental-websocket scripts/design/verify_ui_redesign.mjs http://127.0.0.1:8840/ outputs/ux/ui-redesign
```

השרת המבודד משתמש בתיקיית נתונים זמנית ומחזיק מפתחות בזיכרון בלבד: אין גישה למנהל האישורים של Windows, לא נפתח דפדפן ולא נבדקים עדכונים. הספרים בספריית הבדיקה נוצרים דרך דוגמת Auto של האפליקציה, ללא עלות. בבדיקות המחיקה תיבת האישור מבוטלת, כך ששום דבר לא נמחק.
