מדריך מפתח API

מהו מפתח API

מפתח API הוא סיסמה ארוכה שמזהה את החשבון שלך אצל ספק המודלים. התוכנה משתמשת בו כדי לשלוח טקסט לתרגום, והספק מחייב אותך לפי השימוש בפועל. מנוי ל-ChatGPT או ל-Claude אינו כולל קרדיט API: זה חשבון וחיוב נפרדים.

מומלץ לבטל טעינה אוטומטית (auto-recharge) ולהגדיר מגבלה חודשית. הטעינה המינימלית היא בדרך כלל סביב 5 דולר.

המלצה: OpenAI gpt-6-luna

gpt-6-luna היא האפשרות הזולה ביותר מבין המודלים שהתוכנה מכירה את מחירם: מחיר מחירון של 0.10 דולר למיליון טוקנים בקלט ו-0.50 דולר למיליון טוקנים בפלט (נכון ל-2026-10-05). הערכת העלות בתוכנה מציגה את ההערכה האמיתית לכל ספר לפני שמתחילים.

OpenAI

  1. היכנס או הירשם ב-דף המפתחות של OpenAI ולחץ Create new secret key.
  2. העתק את המפתח מיד: הוא מוצג פעם אחת.
  3. הוסף קרדיט מראש ב-דף החיוב של OpenAI, כבה auto-recharge והגדר מגבלה חודשית.

Anthropic (Claude)

  1. צור מפתח ב-דף המפתחות של Anthropic.
  2. הוסף קרדיט ב-דף החיוב של Anthropic, כבה טעינה אוטומטית והגדר מגבלת הוצאה חודשית.

DeepSeek

  1. צור מפתח ב-דף המפתחות של DeepSeek.
  2. טען יתרה ב-דף הטעינה של DeepSeek.

הזנת המפתח בתוכנה

הדבק את המפתח במסך ההגדרות של התוכנה. הוא נשמר מוצפן ב-Windows Credential Manager ונשלח רק לספק שבחרת. ראה פרטיות.

API key guide

What is an API key

An API key is a long secret string that identifies your account with a model provider. The app uses it to send text for translation, and the provider bills you for actual usage. A ChatGPT or Claude subscription does not include API credit: the API is a separate account with separate billing.

We recommend turning auto-recharge off and setting a monthly limit. The minimum prepaid top-up is usually around $5.

Recommendation: OpenAI gpt-6-luna

gpt-6-luna is the cheapest option among the models whose prices the app knows: list rate $0.10 per million input tokens and $0.50 per million output tokens (as of 2026-10-05). The app's cost preview shows the real per-book estimate before you start.

OpenAI

  1. Sign in or sign up, then create a key on the OpenAI keys page (Create new secret key).
  2. Copy the key right away: it is shown only once.
  3. Add prepaid credit on the OpenAI billing page, turn auto-recharge off and set a monthly limit.

Anthropic (Claude)

  1. Create a key on the Anthropic keys page.
  2. Add credit on the Anthropic billing page, turn auto-reload off and set a monthly spend limit.

DeepSeek

  1. Create a key on the DeepSeek keys page.
  2. Top up your balance on the DeepSeek top-up page.

Entering the key in the app

Paste the key in the app's settings. It is stored encrypted in Windows Credential Manager and sent only to the provider you chose. See privacy.
