# Gate 8 contract — conditional semantic review and one correction

- Component/owner: `semantic_review.py` orchestrates risk selection, a replaceable focused critic, strict claim validation, one optional correction and deterministic rechecks. Sol owns contract, verification, audit and Git; one scoped Claude Code Sonnet builder owns implementation. No Astra/Opus without written escalation.
- Input: validated Gate-4 structure and Gate-5 glossary; a schema-1 `translation-draft@1` record from Gate 7 bound to the same canonical scholarly request, exact source/policy/cache identity and unapproved text. The original source and draft remain immutable. No free-form caller source text. Drafts with failed provider status or no Hebrew text are not reviewable.
- Output: schema-1 `semantic-review@1` record with source/draft hashes and provenance; risk triggers, review disposition, source span → target span → typed error claims, false-positive/dismissal evidence, at most one corrected Hebrew candidate, before/after formal findings, critic/corrector prompt/model/usage/cost/status, and `approved=false`. Status includes `not_triggered`, `needs_human`, `corrected_unapproved`, `needs_human_or_budget`, or explicit failure. Never overwrite the Gate-7 draft.
- Risk policy: trigger only on selected OCR warnings, negation, scope/modality, quantifiers, applicable unapproved loaded term, Japanese ambiguity/context dependence, or formal findings. Deterministic flags route a focused critic; they do not assert semantic errors. Style differences alone do not justify correction. OCR/source uncertainty routes to human with evidence and no model repair of source.
- Critic boundary: source target unit, bounded same-reading context, applicable approved terms and Hebrew draft; no entire PDF, translator rationale or model name. A replaceable mock/fake path supports offline construction. A real critic, if later enabled, uses the Gate-6/7 OpenAI adapter and a shared list-price budget, one critic call and at most one correction call, no retries; report actual charge unknown. Strict JSON response and span/type validation; malformed, unsupported or ungrounded claims go to human. Do not silently accept model claims as fact.
- Correction: only a validated material claim may trigger one bounded correction. Recheck corrected candidate with Gate-7 formal checker and targeted semantic claim; a new formal failure or unresolved/disputed meaning goes to human. A corrected candidate remains unapproved. Preserve original, critic claims and one correction history. No recursive critique or style polishing.
- Errors/side effects: invalid or stale source/draft/policy fails before provider; API missing/failure/usage unmetered/budget exhaustion is explicit and never approved. CLI may write one exclusive review JSON under ignored output, refusing collisions with structure/glossary/draft/source evidence and source/test tree; metadata only on stdout. No source mutation, approved memory write, export, or remote service.
- Acceptance: existing suite plus offline producer-consumer tests of risk/no-risk routing, known negation or quantifier error with valid source/target spans, dismissed false positive, single correction then recheck, unresolved/human path, OCR refusal, malformed/stale draft and critic JSON, no second correction, formal regression, budget/missing-key/transport negatives, and public mock CLI. Synthetic cases establish software behavior only, not reviewer accuracy or scholarly quality. A real model probe is optional only under a separately logged bounded call; absence of an available key does not block offline software construction.
- Out of scope: Gate-9 human UI/approval/export, gold-set reviewer selection (Gate 10), whole-document review, second reviewer, source/OCR repair, new provider/profile, persistent cache, actual quality PASS.
- Development budget: one Sonnet builder invocation, reported list estimate ceiling $2, wall <=600s, soft 25/hard 60 observed tool calls; one reproduced-defect focused fix reserve $1. Runtime provider calls: zero during offline build. Sol/Claude subscription charges may be unknown; Opus/Astra zero.
