# Gate 4 — source resolution and versioned segmentation

- component: validated source-reading handoff, then source-linked translation units. Conductor Sol; builder Sonnet. Base 316953664120c119edc70c8faa37f459dbcdd9f9; ARCHITECTURE.md adopted explicitly by user, package verified.
- owns: scholarly_translation/source_reading.py, segmentation.py, __main__.py; tests/test_structure.py; README.md. Do not edit extraction, OCR, records, old tests, policy/architecture/audit, Git or dependencies. No Bash/web/agents. Read this contract, relevant source record/OCR output fields, existing fixture helpers, and architecture source-handoff section only.
- input: validated schema-3 PDF Document; optional Gate-3 OCR schema-1 bundle; optional explicit human decisions; optional boundary specification; optional previous structure result. Local interfaces are pure except explicit CLI files. No UI/API/network. Existing source evidence is immutable, not migrated or overwritten.
- source reader: validate OCR root schema/stage/document_id/source_hash and canonical base_extraction_hash against Document (same canonical JSON as ocr.py); reject duplicate/unknown page IDs/numbers, mismatched PDF dimensions, invalid image URI/hash/dimensions, malformed words/spans/confidences/bboxes, nonfinite coordinates and inconsistent pixel-to-PDF mapping. Preserve exact transcription and all digital/OCR alternatives, warnings and evidence anchors. No ID match alone counts as approval. A page with render/engine error or empty transcription cannot be accepted. Pure validation verifies declared hashes/formats and references, not image file contents; document this limit (file bytes are verified at OCR production).
- decisions: JSON mapping page_id -> {origin: digital|ocr, candidate_hash: exact candidate hash emitted by reader, actor: nonempty, actor_kind: human, reason: nonempty}. Unsupported fields/types/actions, unknown/stale candidate hashes, duplicate/unknown decisions rejected through StructureError. No default approval. Without an explicit decision, reading is unresolved (reason unreviewed_source / missing_source); emit alternatives and zero units. Model actor cannot resolve. Low-confidence but nonempty OCR may be resolved only by explicit human choice and retains its warnings. Tests simulate human decisions on original construction fixtures; conductor must never manufacture acceptance for real scholarly source.
- output: structure JSON schema 1, document/PDF/source URI+language and canonical input hash, stage structure@1; page readings with stable reading_id, version, exact text/text_hash, selected evidence origin/hash, page ID/number, resolved|unresolved status/reasons, decision record and all alternatives (line/word source anchors, boxes and OCR image reference). Reading correction is a new derived version with prior reading reference; no source correction algorithm. Freeze exact shapes in tests, do not add profile fields.
- segmentation: resolved reading -> units containing stable unit_id, unit_version, reading ID/version/hash, document/page IDs/language, exact half-open source span/text, intersecting evidence-region anchors with PDF bbox and OCR image/word location, warnings/status (unreviewed translation, never approved). Default units are source lines; boundaries JSON mapping page_id -> list of [start,end] allows merging/splitting lines. Never silently join/normalize source. Exact source slices, positive spans and valid bounds mandatory. No units for unresolved reading. Header/footnote/citation/formula/numbers remain ordinary source-backed content, never dropped or reassigned semantically. Footnote/citation/formula markers are span-linked annotations/candidates only; do not decide footnote association or scholarly meaning.
- continuity: public deterministic check returns typed findings for missing non-whitespace source characters, overlapping/duplicate unit coverage, mismatched source text, invalid anchors. Gaps consisting only of line separators may be unsegmented but remain in the immutable reading. Demonstrate deliberately omitted and duplicated units. Invalid user boundaries rejected, not repaired.
- revisions: global segmentation revision/id and parent revision reference. Re-running identical plan/evidence returns same identities; unchanged units retain ID/version. Changed boundaries create new deterministic IDs, increment affected version and preserve predecessor IDs by overlap. Previous structure must match document/PDF lineage, validate before revision. Changing selected reading creates a new reading version with prior ID, invalidating units dependent on old reading. Preserve prior complete reading/unit snapshots in non-recursively nested history; no old artifact loss. A persisted consumer validates current and historical text spans/hash/IDs/source anchors; reject malformed/tampered data clearly. Source evidence never overwritten.
- errors: StructureError for wrong shapes/versions/lineage/hash/stale decisions/invalid spans, no private text/values in errors. Expected unresolved source is data, not a fabricated success. CLI returns nonzero on invalid input, no traceback; do not write output on validation failure.
- side_effects: `python -B -m scholarly_translation structure DOCUMENT_JSON --output outputs/gate4/structure.json [--ocr OCR_JSON] [--decisions DECISIONS_JSON] [--boundaries BOUNDARIES_JSON] [--previous PREVIOUS_JSON]`; `inspect-structure STRUCTURE_JSON` validates persisted result and shows status/IDs/provenance/continuity. Output is a separate derived JSON. No model calls in product.
