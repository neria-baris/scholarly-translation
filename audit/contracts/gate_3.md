# Gate 3 — local OCR fallback

- component: image-only/failed-text page OCR, one local engine; conductor Sol, builder Sonnet.
- owns: scholarly_translation/ocr.py, __main__.py; tests/test_ocr.py, tests/ocr_fixture.py; README.md. No changes to records/schema 3, extraction, other tests or audit/Git; no Bash/web/agents.
- input: validated Gate 2 Document schema 3, exact original PDF path whose bytes match input_hash; language en/fr/ja mapped to eng/fra/jpn; Tesseract path and optional tessdata directory; bounded timeout. Current local engine C:/Program Files/Tesseract-OCR/tesseract.exe, 5.4.0; best language weights locally cache/ocr/tessdata (never committed). Inputs are explicit, not credentials/environment dumps.
- output: separate OCR bundle JSON schema 1, never overwrites Document/source_text. Include document/page IDs, source PDF URI/hash, SHA-256 of canonical base extraction JSON, stage local-ocr@1, engine actual version/language/model file hash when available, selected-page image URI/hash/dimensions and PDF width/height. Per page transcription plus per-word text/spans, confidence, pixel bbox and proportional PDF bbox [x0,top,x1,bottom]. Pages status needs_human and eligible_for_translation false, warnings ocr_unreviewed plus low_confidence/empty/error as applicable. OCR confidence is not proof of accuracy. Omitted pages explicitly listed skipped with reason digital_text_available.
- selection: default OCR only pages with empty extracted text. Optional explicit page list for demonstrably failed digital text, flagged forced_page_review; validate page selection. One engine per selected page, no retries/LLM. Render selected pages at 200 DPI via pdfplumber/PDFium. Do not render/OCR digital pages by default. Never edit existing extraction output.
- invariants: original image and transcription are retained; all selected pages yield an outcome even on timeout/missing language/engine failure; no success without words; preserve uncertainties; no automatic translation of OCR output. Bound subprocess with timeout, list args (no shell), discard engine stderr/private paths from errors. Parse TSV deterministically; validate finite confidence 0..100 and in-image bboxes; reconstruct line breaks using Tesseract block/par/line IDs and exact word offsets, no silent text repair.
- errors: missing PDF/hash mismatch/unsupported language/invalid timeout or page selection -> bounded OCRInputError before work. Engine unavailable/timeout/nonzero/malformed TSV -> selected-page needs_human with error code, empty text; retain rendered source. No secrets/private transcript in application logs.
- side_effects: explicit output folder with ocr.json and selected image PNGs; local subprocess only, no network. Public CLI `ocr-pdf INPUT DOCUMENT_JSON --language en --output outputs/gate3 --tesseract PATH --tessdata-dir DIR` (optional --pages 1 2). Only conductor invokes tests.
- acceptance: deterministic TSV parser/confidence/box/span tests; fake engine success/failure/timeout and selection/hash mismatch/producer-consumer tests. Actual image-only English/French fixtures with clear and blurred pages; generate raster images then embed with reportlab (no text layer), actual extraction empty, actual Tesseract transcription and boxes retained; clear sentinel recognized, uncertain page stays needs_human, digital page skipped. Japanese fixture if locally available font/model may be demonstrated, not required for real accuracy claims. Real CLI produces inspectable JSON and images. Tests use unittest with current venv, live engine test skipped only when absent (conductor must run it here).
- out_of_scope: automatic source reconstruction/approval, OCR engine comparison, semantic routing, translation, schema migration, UI/server; fixtures prove construction only, real OCR pilot remains preliminary.
- budget: one Sonnet implementation call estimate limit $2, reserve $1 for one demonstrated targeted fix; actual charge/quota unknown. Soft 20/hard instruction 60 tools, 10-minute timeout, no external product API. End with concise delivery and stop.
